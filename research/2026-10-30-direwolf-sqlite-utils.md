## Dire Wolf — PROMISING / A25
- Repository: https://github.com/wb2osz/direwolf ; author John Langner (WB2OSZ). Gold factors: 5 utility + 4 working evidence + 4 reusability + 4 novelty + 5 docs + 3 maintenance = **25/30**.
- Value: mature soundcard TNC for AX.25/APRS packet radio with digipeater, IGate, tracker, FX.25 and IL2P forward error correction. Reuse targets: `src/demod_afsk.c`, `src/demod_9600.c`, `src/ax25_pad.c`, `src/ax25_link.c`, `src/kiss_frame.c`, `src/kissnet.c`, `src/kissserial.c`, `src/fx25_*.c`, `src/il2p_*.c`, `src/igate.c`, `src/digipeater.c`, `src/telemetry.c`; synthetic tests in `test/CMakeLists.txt` and `test/scripts/`.
- Runtime: C/CMake; Linux/macOS/Windows, with soundcard and radio for actual RF. Optional ALSA, PortAudio, Hamlib, GPSD, GPIO/PTT dependencies vary by target. Local amateur radio and RF regulations apply to transmission.
- Release evidence: latest published non-prerelease [1.8.1](https://github.com/wb2osz/direwolf/releases/tag/1.8.1) **2025-11-13**. Master at `eda1383` **2026-05-19** declares **1.8.2 Development** in `CMakeLists.txt`, but no 1.8.2 GitHub release was found. Dev commit `4edb377` **2026-10-16** passed [5/5 Windows/macOS/Ubuntu build jobs](https://github.com/wb2osz/direwolf/actions/runs/38972134998), including successful build and test steps. **Important:** `.github/workflows/ci.yml` marks the test step `continue-on-error: true`, so the green workflow is not a mandatory test gate. [Master C++ CodeQL](https://github.com/wb2osz/direwolf/actions/runs/40900328790) and [Python CodeQL](https://github.com/wb2osz/direwolf/actions/runs/40900568816) succeeded 2026-10-29, but do not build master.
- **Security finding:** Upstream `CHANGES.md` states **1.8.2 (May 2026)** backports fixes for KISS stack-buffer-overflow **CVE-2025-34457** and MIC-E packet abort **CVE-2025-34458**. Master commits `4eb3835` and `338f56c` include backports. The last published stable 1.8.1 predates those fixes; **do not assume 1.8.1 is patched**. Check patch commits in any distribution and isolate untrusted KISS network inputs; no exploit reproduction performed.
- License: `LICENSE` contains GPLv2; `src/direwolf.c`, `src/kiss_frame.c` and `src/igate.c` explicitly state GPL-2.0-or-later. `external/LICENSE` warns bundled code includes BSD/GPL/other terms. No source copied; preserve all notices before reuse.
- Recursive leads: `wb2osz/hrot` and APRS ecosystem, Reticulum's generic KISS transport (protocol-level interoperability lead only), packet capture and decoder regression tests. Next: obtain a tested security-fixed release, confirm KISS/FX25/IL2P round trips, bind/interface restrictions and actual RF validation.

## sqlite-utils — VERIFIED upstream / S26
- Repository: https://github.com/simonw/sqlite-utils ; author Simon Willison. Factors: 5 utility + 4 working evidence + 5 reusability + 3 novelty + 5 docs + 4 maintenance = **26/30**.
- Value: portable local-data ingestion and manipulation toolkit with both CLI and Python APIs. Source: `sqlite_utils/db.py` (Database/Table, schema/FTS), `sqlite_utils/cli.py` (CSV/TSV/JSON import and query), `sqlite_utils/migrations.py`, `sqlite_utils/plugins.py` and `hookspecs.py` (pluggy), `sqlite_utils/create_table_parser.py`, `sqlite_utils/utils.py`; `tests/` covers FTS, migrations, schema transforms, streaming, CLI and SQLite behavior.
- Runtime: `pip install sqlite-utils`; `pyproject.toml` requires Python >=3.10 and declares version **4.2.1**. Optional SpatiaLite and NumPy support in selected tests/features; no Termux execution established.
- Release: [4.2.1](https://github.com/simonw/sqlite-utils/releases/tag/4.2.1) **2026-08-13**, a patch for the 4.2 `typing_extensions` missing dependency.
- Upstream test evidence: [2026-09-22 main Test](https://github.com/simonw/sqlite-utils/actions/runs/35768210531) succeeded; first page of 30 jobs all successful. On **2026-10-11**, [SQLite version compatibility](https://github.com/simonw/sqlite-utils/actions/runs/38097836285) (2/2) and [coverage](https://github.com/simonw/sqlite-utils/actions/runs/38097836249) (1/1) succeeded, but [main full Test](https://github.com/simonw/sqlite-utils/actions/runs/38097836294) **failed** at macOS Python 3.14 `ty` step, with 22 matrix jobs cancelled. [2026-10-30 main CodeQL](https://github.com/simonw/sqlite-utils/actions/runs/41001821939) succeeded. Do not describe current-main full CI as green or conflate type-check failure with a demonstrated SQLite runtime failure.
- License: Apache-2.0 in root `LICENSE` and `pyproject.toml`; dependency and plugin licenses remain separate. Plugins execute code and SQLite extensions must be treated as privileged; do not load untrusted plugins. Back up databases before destructive migrations.
- Recursive leads: `simonw/datasette` for publishing, `simonw/csvs-to-sqlite` and `simonw/db-to-sqlite` for ingestion, `sqlite-fts4` direct dependency; Miller is a complementary data CLI, not a proven integration. Next: run CSV/JSONL round trips and FTS tests on a pinned Python/SQLite matrix; isolate the macOS `ty` failure.
