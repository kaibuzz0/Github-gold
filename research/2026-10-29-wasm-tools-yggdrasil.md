**Upstream working evidence:** [2026-10-24 release CI run 40102009196](https://github.com/yggdrasil-network/yggdrasil-go/actions/runs/40102009196) passed **13/13 jobs**: lint, CodeQL, Go 1.26/1.27 Linux/macOS/Windows build-and-test, FreeBSD/OpenBSD cross-build, aggregator. [Packaging run](https://github.com/yggdrasil-network/yggdrasil-go/actions/runs/40102062103) passed but is not a live network test.

**Critical security caveat:** [src/admin/admin.go](https://github.com/yggdrasil-network/yggdrasil-go/blob/develop/src/admin/admin.go) explicitly contains `TODO: Add authentication` and supports TCP as well as Unix admin listeners. Do not expose it to an untrusted network. Unix listener attempts mode 0660, which still requires local user/group review. Configuration contains identity private keys. No independent peer routing, NAT, cryptographic, or DoS tests performed. Compare Nebula's certificate/ACL model rather than assuming equivalent controls.
