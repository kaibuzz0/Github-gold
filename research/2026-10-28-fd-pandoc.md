**Working evidence:** [PR CICD run 34198170327](https://github.com/sharkdp/fd/actions/runs/34198170327), 2026-09-09, had 18 jobs concluded success and one Winget publish job skipped. Includes cargo fmt, clippy, minimum supported Rust version and cross-platform Linux/macOS/Windows build/test matrix. This is older PR-branch evidence, **not** proof current master passed CI.

**Reusable source inspected:** `src/walk.rs` uses `ignore::WalkParallel`, bounded channels, batching and result buffering. `src/exec/mod.rs` implements per-result vs batch execution; `src/exec/command.rs` is a companion source. `src/sanitize.rs` escapes C0/C1, bidi and other formatting characters when displaying untrusted filenames on TTY. `src/main.rs` wires CLI options, regex and glob matching. `tests/tests.rs` contains integration fixtures. The manifest depends on `ignore = 0.4.28` and `globset = 0.4`, crates from ripgrep's ecosystem, and `regex`/`aho-corasick`. It is not a ripgrep fork or direct runtime integration.

**Caveats:** Hidden and gitignored files are excluded by default; `-H`/`-I` or `-u` change coverage. `-x` and `-X` run external programs with the caller's permissions; unsafe templates or untrusted paths can cause damage. Terminal sanitization does not secure subprocess invocation. Verify target-specific packages, licenses and symlink handling before reuse.
