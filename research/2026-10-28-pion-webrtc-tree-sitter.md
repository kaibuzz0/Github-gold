## Pion WebRTC — VERIFIED (upstream) / S29

**Upstream:** https://github.com/pion/webrtc — pure-Go WebRTC v4 module; [MIT license](https://github.com/pion/webrtc/blob/main/LICENSE), [README](https://github.com/pion/webrtc/blob/main/README.md), [go.mod](https://github.com/pion/webrtc/blob/main/go.mod) (`go 1.24.0`).

**Exact reusable source:** [peerconnection.go](https://github.com/pion/webrtc/blob/main/peerconnection.go) implements PeerConnection state, SDP negotiation and transport lifecycle; [datachannel.go](https://github.com/pion/webrtc/blob/main/datachannel.go) is the SCTP DataChannel API; [settingengine.go](https://github.com/pion/webrtc/blob/main/settingengine.go) configures ICE, candidate filters, DTLS and replay protection; [interceptor.go](https://github.com/pion/webrtc/blob/main/interceptor.go) registers NACK, RTCP reports, TWCC and stats; [ICE restart](https://github.com/pion/webrtc/tree/main/examples/ice-restart) and [DataChannel flow control](https://github.com/pion/webrtc/tree/main/examples/data-channels-flow-control) are application-level patterns; [browser E2E tests](https://github.com/pion/webrtc/blob/main/e2e/e2e_test.go) exercise Chrome WebDriver audio. [DESIGN.md](https://github.com/pion/webrtc/blob/main/DESIGN.md) clarifies the library transports media but does not create it.

**Release and CI (2026-10-28):** [stable v4.2.26](https://github.com/pion/webrtc/releases/tag/v4.2.26) released 16:37 UTC on commit `0e35f8059c`, including an SDP mutation-race fix. ## Tree-sitter — VERIFIED (upstream) / S29

**Upstream:** https://github.com/tree-sitter/tree-sitter — [MIT license](https://github.com/tree-sitter/tree-sitter/blob/master/LICENSE), [README](https://github.com/tree-sitter/tree-sitter/blob/master/README.md), [Cargo workspace](https://github.com/tree-sitter/tree-sitter/blob/master/Cargo.toml) (Rust 1.90, current workspace `0.28.0` development).

**Exact reusable source:** [lib/src/parser.c](https://github.com/tree-sitter/tree-sitter/blob/master/lib/src/parser.c) is the incremental C parser; [get_changed_ranges.c](https://github.com/tree-sitter/tree-sitter/blob/master/lib/src/get_changed_ranges.c) computes changed syntax ranges; [query.c](https://github.com/tree-sitter/tree-sitter/blob/master/lib/src/query.c) handles structural queries; [public API](https://github.com/tree-sitter/tree-sitter/blob/master/lib/include/tree_sitter/api.h) documents ABI compatibility (13–15); [grammar generator](https://github.com/tree-sitter/tree-sitter/blob/master/crates/generate/src/generate.rs) turns grammar definitions into parser tables; [highlight module](https://github.com/tree-sitter/tree-sitter/blob/master/crates/highlight/src/highlight.rs) applies query-based highlighting; [CLI](https://github.com/tree-sitter/tree-sitter/blob/master/crates/cli/README.md) supports generate/test/parse; [WASM bindings](https://github.com/tree-sitter/tree-sitter/blob/master/lib/binding_web/README.md) enable browser/Node/Deno parsing.

**Release and CI:** [stable v0.27.1](https://github.com/tree-sitter/tree-sitter/releases/tag/v0.27.1) released 2026-10-08, with UTF-16, grammar generation, query and error-recovery fixes. **Do not call master workspace v0.28.0 a stable release.** [2026-10-28 master CI](https://github.com/tree-sitter/tree-sitter/actions/runs/40640264375) passed **15/15 jobs**, including checks, consistency, 12 target builds and sanitizer job. [Sanitizer workflow](https://github.com/tree-sitter/tree-sitter/blob/master/.github/workflows/sanitize.yml) explicitly runs tests with UBSAN and ASAN; [build workflow](https://github.com/tree-sitter/tree-sitter/blob/master/.github/workflows/build.yml) includes Linux, Windows, macOS, illumos and WASM targets, with some cross-compile-only paths. Do not equate successful cross-compilation with runtime testing on every platform.

**Requirements:** Embeddable C runtime is dependency-free. CLI supports prebuilt binaries and `cargo install --locked tree-sitter-cli`; generation requires Node.js and grammar parse/test commands require C/C++ compilers. WASM uses separate grammar `.wasm` modules. ABI 13–15 is the supported runtime range in inspected header; generated grammar forward compatibility is not guaranteed.

**Ecosystem recursion:** Inspected [JavaScript grammar](https://github.com/tree-sitter/tree-sitter-javascript/blob/master/grammar.js) with MIT SPDX header and confirmed [Python grammar](https://github.com/tree-sitter/tree-sitter-python) repository; grammar repositories have independent licenses, tests and release schedules. Additional Rust grammar and editor integrations remain leads, not verified integrations.

**Licensing and security:** MIT core; third-party grammar and binding dependencies separately licensed. Native grammars are compiled executable code; review/sandbox untrusted grammar packages, and enforce parser time/memory limits on hostile inputs. Passing sanitizer CI is evidence of tests run, not a general memory-safety guarantee. No independent parser generation, malicious-input test or fuzz campaign.

**Next:** Grammar ABI regression corpus across v0.27.1/0.28 development, incremental edit invariants, query memory limits, WASM vs native grammar isolation, language grammar maintenance/license audits.
